# Project GMAO Documentation

Welcome to the comprehensive documentation for **Project GMAO** (Gestion de Maintenance Assistée par Ordinateur) - a modern, AI-powered maintenance management system.

## 🚀 Overview

Project GMAO is a full-stack maintenance management platform that combines:

- **Real-time IoT Integration** - Monitor equipment status and performance
- **AI-Powered Predictions** - Machine learning models for predictive maintenance
- **RAG Chatbot** - Intelligent assistant with document retrieval capabilities
- **Interactive Dashboard** - Visualize maintenance data and KPIs
- **Role-Based Access Control** - Admin and Operator user roles
- **Maintenance Planning** - Schedule and delegate maintenance tasks

## 🎯 Key Features

### Real-Time Monitoring
Monitor industrial equipment in real-time with IoT sensor integration and live data streaming.

### Predictive Maintenance
Machine learning models trained on historical data predict equipment failures before they occur.

### Intelligent Chatbot
RAG (Retrieval Augmented Generation) chatbot that answers questions based on uploaded technical documentation.

### Task Delegation
Admins can delegate maintenance tasks to operators with full tracking and notification system.

### Data Visualization
Interactive charts and dashboards for maintenance KPIs, failure analysis, and performance metrics.

## 🛠️ Technology Stack

### Frontend
- **Next.js 15** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **Shadcn/ui** - Component library
- **TanStack Query** - Data fetching and caching

### Backend
- **Supabase** - PostgreSQL database with real-time capabilities
- **Python FastAPI** - ML prediction API
- **pgvector** - Vector similarity search for RAG
- **Row Level Security** - Database-level authorization

### AI/ML
- **Scikit-learn** - Machine learning models
- **Cohere** - Embedding generation
- **OpenAI/Cohere/Mistral/Gemini** - LLM integration
- **TensorFlow** - Model training and inference

### DevOps
- **Turbo** - Monorepo build system
- **pnpm** - Fast package manager
- **Git** - Version control
- **Docker** - Containerization (optional)
